# Alembic Migration Versions

This directory contains database migration scripts generated by Alembic.

## Creating a new migration

To generate a new migration after modifying models:

```bash
alembic revision --autogenerate -m "description of changes"
```

## Applying migrations

To upgrade database to latest version:

```bash
alembic upgrade head
```

## Rolling back migrations

To downgrade one version:

```bash
alembic downgrade -1
```

To downgrade to specific version:

```bash
alembic downgrade <revision_id>
```

## Viewing migration history

```bash
alembic history
alembic current
```
